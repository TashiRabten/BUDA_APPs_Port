SuiteBUDA Privacy Policy

Last update: 21 November 2026

What SuiteBUDA is

SuiteBUDA is a desktop application that helps the developer of the BUDA apps do their work. It runs on the user's own computer.

How SuiteBUDA uses Google Drive

SuiteBUDA uses the program rclone, on the user's own computer, with the user's own Google account. With this access, SuiteBUDA copies the user's own files (backups of the apps and the folders of finished work) to the user's own Google Drive, checks each copy, and brings the files back when the user asks.

SuiteBUDA uses this access only for its own folders in the user's Drive (for example Backups/BUDA-protecao and BUDA-docs). It does not read, change or delete other files in the Drive.

Where the data goes

The data goes only between the user's computer and the user's Google Drive. SuiteBUDA does not send data to the developer or to other persons or companies. SuiteBUDA does not show advertisements, does not sell data and does not collect usage statistics.

SuiteBUDA's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where the access is kept

rclone keeps the access token in its configuration file on the user's computer. The user can remove the access at any time on the page Google Account permissions.

Contact

For questions, open an issue in the developer's repositories at github.com/TashiRabten.

Política de privacidade do SuiteBUDA

O SuiteBUDA roda no computador do próprio usuário. Com a conta Google do usuário, ele usa o rclone para copiar os arquivos do próprio usuário (os backups dos apps e as pastas de trabalho terminado) para o Google Drive do próprio usuário, conferir cada cópia e trazer os arquivos de volta quando o usuário pede. Ele usa esse acesso só nas pastas dele no Drive e não lê, muda ou apaga outros arquivos.

Os dados vão só entre o computador e o Drive do usuário. Nada vai para o desenvolvedor nem para outras pessoas ou empresas; não há anúncios, venda de dados nem estatísticas de uso. O acesso fica no arquivo de configuração do rclone, no computador do usuário, e pode ser retirado a qualquer momento em myaccount.google.com/permissions.
